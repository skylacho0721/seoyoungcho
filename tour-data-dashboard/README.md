# 공공데이터 여행 대시보드

키워드 하나(지역명·관광지명)를 입력하면 **한국관광공사 TourAPI**(관광지·숙박·음식점·축제 등)와
**기상청 단기예보 API**(현재 날씨) 두 개의 공공데이터를 모아 화면에 보여주고, 결과를 **엑셀(.xlsx)**로
다운로드할 수 있는 대시보드입니다.

## 1. 공공데이터포털에서 API 키 발급받기

1. [data.go.kr](https://www.data.go.kr) 회원가입 및 로그인
2. 아래 두 개의 API를 각각 검색해서 **활용신청**
   - `한국관광공사_국문 관광정보 서비스_GW` (TourAPI)
   - `기상청_단기예보 ((구)_동네예보) 조회서비스`
   - 둘 다 **자동승인** 상품이라 신청 즉시 사용 가능합니다.
3. 마이페이지 > **개발계정** 에서 발급된 인증키 중 **일반 인증키(Decoding)** 값을 복사

## 2. 환경변수 설정

```bash
cp .env.example .env
```

`.env` 파일을 열어 `TOUR_API_KEY`, `WEATHER_API_KEY` 값을 위에서 복사한 키로 교체하세요.

## 3. 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속 후 키워드(예: `경주`, `강릉`, `전주 한옥마을`)를
입력하고 검색하면 결과가 표와 분류별 그래프로 표시되고, **엑셀 다운로드** 버튼으로 `.xlsx` 파일을
받을 수 있습니다.

## 동작 방식

- 브라우저 → 내 서버(`/api/search?keyword=...`) → 공공데이터포털 API 순서로 호출합니다.
  (공공데이터포털 API는 브라우저에서 직접 호출 시 CORS로 막히는 경우가 많아, 서버가 대신
  요청하고 결과만 JSON으로 내려줍니다. API 키도 서버에만 있어 노출되지 않습니다.)
- 입력한 키워드가 주요 도시명(서울, 부산, 강릉 등)을 포함하면 해당 지역의 현재 날씨도 함께 조회합니다.
- 엑셀 다운로드는 서버 없이 브라우저에서 [SheetJS](https://sheetjs.com)로 즉시 생성됩니다.
  시트는 `관광정보`, `날씨`, `요약`(분류별 건수) 3개로 구성됩니다.

## 다른 공공데이터로 바꾸고 싶다면

`server.js`의 `searchTourItems`, `getWeather` 함수를 참고해서 원하는 API 호출 함수를 추가하고,
`app.get('/api/search', ...)` 안에서 함께 호출한 뒤 응답 JSON에 합치면 됩니다.
